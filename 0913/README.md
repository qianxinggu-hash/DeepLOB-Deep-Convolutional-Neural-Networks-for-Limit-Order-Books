# 0913：论文 GP-QVI 方法的 gamma 敏感性研究

本目录聚焦 Guilbaud–Pham 的**均值效用与二次库存惩罚方法**，每档均保留原 GP-QVI 的限价单及市价库存调整。完整重放2026年7月19个测试交易日，只改变gamma，其余控制、期限、库存上限、校准和费用固定。

## 研究框架

目标形式为期末清算财富的期望减去库存风险惩罚：

```text
E[terminal_liquidation_wealth] - gamma × E[∫ inventory(t)² dt]
```

gamma是风险偏好系数；本轮研究不同gamma下的交易行为、库存暴露和经验风险收益点，不按本月收益选择最优gamma。

网格按论文表6的等比减半结构生成 `50 / 2^i, i=0…13`，并保留此前的 `5 / 1 / 0.5 / 0.1 / 0.05 / 0.01 / 0` 七个核对档位，共21档。论文表中的展示值有舍入，本研究使用等比生成的完整浮点值。

降低gamma后，策略更愿意挂单和持仓，库存暴露上升；当前真实数据回放中净收益恶化。gamma=0.1时，毛收益已亏损约24,364港元，另有约20,936港元手续费，亏损并不只是交易费用。

gamma从5增至50的实际成交与现金损益相同，说明当前回放路径上已饱和；整个理论状态网格仍可能有变化。gamma从0.5降到0.390625时成交出现明显跃迁，符合离散动作和库存状态下的阈值效应，不能假定成交与gamma之间是平滑线性关系。

理论市价区域和实际市价次数衡量不同内容：前者是给定库存、spread和期限时的政策动作，后者还依赖实际挂单、成交及库存路径。例如gamma=1的实际市价次数比gamma=5多，并不推翻大gamma扩大理论减仓区域的机制。

## 指标与单位

- 库存RMS = `sqrt(∫q(t)²dt / 回放时长)`，同时考虑持仓大小与时间；峰值库存另计。
- 库存计时从首报价+5ms至日终到期+5ms，持仓跨午休也计入。市价事件时钟与原订单生命周期对齐，现金流和成交决定保持原样。
- 理论市价区域为剩余300秒时，在6个spread × 21个库存状态中，市价目标不同于当前库存的比例；对19天和6个时段等权平均。它不是实际访问状态占比。
- 全日 `gamma × ∫q²dt` 是回放惩罚诊断量，不是每次滚动300秒求解的Bellman价值，也不用于跨gamma比较最优目标值。
- 经验风险收益散点使用19个每日净损益的样本标准差和均值；它不是原论文的Monte Carlo有效前沿或NIR。
- 当前库存q以100股一手计，gamma单位为HKD/手²/秒。若改成股数Y=100q，同一惩罚项的每股系数为 `gamma_share = gamma_lot / 10000`；不能把当前数字5直接视作与论文库存单位等价。
- gamma=0仍属于本轮的线性效用方法，只是取消运行库存惩罚。

## 核对及复现边界

21档均完成19天重放，gamma=5与0906原结果逐日一致，七个旧档位的成交、库存峰值与现金损益也逐日一致。新增计时通过已知长仓/短仓时间积分测试；全部档位通过生命周期、成交来源、费用恒等式、库存边界、积分分布与日终归零核对。

本轮保留0906工程实现：每侧固定100股，市价仅减仓。原论文还优化限价数量与一般冲击控制，因此这不是原表数值的完整复现。3秒离散运行成本按步首库存计算，区间内新成交或先买后卖的暂时库存未连续计入Bellman；实际市价决策只在报价节点评估。新增暴露计时只揭示该近似下的实际库存风险，不改写求解目标。

原论文表6使用模拟路径，当前是19个历史交易日；币种、库存单位、费用和执行代理均不同。触价/L1穿价代理缺少虚拟订单排队、隐藏流动性、确认延迟、最低佣金、借券及市场冲击。每档校准严格使用过去日期，但本月参数曲线仍是敏感性研究，不是已选择参数的独立样本外验证。

后续应固定原GP-QVI方法，检查gamma阈值附近的政策区域、限价成交后的不利价格变动及离散误差，再用未参与研究的数据验证风险收益权衡。
