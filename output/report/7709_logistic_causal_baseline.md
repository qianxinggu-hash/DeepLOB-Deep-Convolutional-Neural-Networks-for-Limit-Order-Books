# HK 07709 因果特征逻辑回归

代码：`analyze_7709_causal_baselines.py`
模型：`checkpoints/7709/7709_logistic_causal.joblib`

这是一个三类分类诊断：用预测时刻已经可见的 25 个订单簿特征，判断未来短窗中间价相对过去短窗是跌、横还是涨。不是交易策略。

---

## 问题怎么写成数学

每个样本是一对 `(x, y)`。

- `x` 是 25 维向量：滞后中间价收益、相对短期均值、价差、多层深度不平衡、单档队列不平衡、买卖间隙、对数深度。全部只用当前及更早的订单簿。
- `y` 属于 `{0, 1, 2}`，对应 Down / Stationary / Up。标签按 DeepLOB Equation (4)，比较过去 20 个与未来 20 个中间价均值，再用训练集上的阈值把中间一段标成横盘。

先把 `x` 按训练集均值、标准差标准化，得到 `z`，让各维量纲一致。后面都在 `z` 上做。

---

## 逻辑回归在做什么

三类各有一组权重 `w_c` 和一个偏置 `b_c`。先算三个线性分数：

```
s_c = w_c · z + b_c     c = Down, Stationary, Up
```

再把分数变成概率（softmax）：

```
P(y = c | z) = exp(s_c) / (exp(s_Down) + exp(s_Stationary) + exp(s_Up))
```

预测取概率最大的那一类。

含义很直接：某个特征变大 1 个标准差，就把某一类的对数几率推高 `w_c` 里对应的那个系数。模型只能学特征的线性组合，学不到档位之间或时间尺度之间的非线性交互。

---

## 怎么训练

训练目标是：让真实类别的概率尽量高，同时不要让权重过大。也就是带 L2 正则的交叉熵：

```
L = -Σ log P(y_i | z_i) + (1 / 2C) ||w||²
```

实现里 `C = 0.1`，正则比较强。`class_weight="balanced"` 按类别人数反加权，避免模型塌到只报一类。

sklearn 管道就是：`StandardScaler` + `LogisticRegression`。三类时用的是真正的 multinomial，不是三个独立的二分类器。

---

## 结果怎么读

测试集 Accuracy 约 58.6%，Macro-F1 约 58.5%，和训练、验证很接近。同一套标签上，原始 DeepLOB 只有约 23.6% Macro-F1。

所以：这套标签本身有可预测成分；逻辑回归给出的是「25 维线性可分程度」的下界。Hybrid 后来接近这个数字，原因见下一节：它并没有把 25 维喂进卷积，而是在 logit 上把这条线性证据和 DeepLOB 加在一起。

---

## Hybrid 怎么把这 25 维接到 DeepLOB 上

代码：`train_7709_hybrid_deeplob.py` 里的 `HybridDeepLOB`。

每个样本同时进两条互不看见对方的支路。

**图像支路。** 最近 100 个 10 档订单簿状态（形状 `1 × 100 × 40`）走原来的 DeepLOB：卷积 → Inception → LSTM，得到 64 维隐向量，再经一层线性映射变成三个分数 `s_lob`。原始 DeepLOB 末尾那层分类器不用了，这里另接一个 `Linear(64 → 3)`。

**特征支路。** 还是上面那个标准化后的 25 维 `z`，不进卷积，单独走一个很小的网络：

```
z (25维) → Linear(25 → 32) → LeakyReLU → Dropout → Linear(32 → 3) → s_aux
```

这相当于逻辑回归再加一层非线性，输出同样是三类分数。

**组合方式是相加，不是拼接。** 最终三个 logit 为

```
s = s_lob + s_aux
```

再对 `s` 做 softmax / 交叉熵，和逻辑回归同一套决策。CNN 看不到这 25 维，辅助支路也看不到订单簿图像。两类证据只在「这一类该得多少分」上叠加。

训练时学习率也拆开：卷积和 `s_lob` 那头用 `3e-4`，特征支路用 `1e-3`，让 25 维更容易先学会。

因此 Hybrid 测试 Macro-F1（约 56%）接近逻辑回归（约 58%），含义是：拉开分数的主要是 `s_aux`；`s_lob` 没有再贡献多少可泛化的新信号。若增益来自更深的图像表征，通常会把 25 维拼进 LSTM 隐状态或卷积输入——当前实现没有那样接。
