# 0920：允许负库存的 GP-QVI gamma 重跑

最新的 L3 方向信号与做市对比见 [0920report](../0920report/README.md)。
下文的 `output/` 文件由本地行情数据生成，部分大文件不纳入 Git 仓库。

断流前后各两分钟剔除、滚动训练成交条件收益并重求 QVI 的后续核对，见 [2026 年 7 月断流清洗与滚动训练结果](output/gap_2m_study/README.md)。

后续对 Hybrid drift、直接终点预测、不同 γ、历史数据质量与成交条件门控的组合实验，见 [2026 年 7 月 drift 与 γ 组合结论](output/combination_study/README.md)。

本目录重新运行 `0913` 的 21 档 gamma 敏感性实验，并把有符号库存设为显式实验条件：库存状态范围为 **-10 至 +10 手**，每手100股。卖方限价单可以从零库存卖出形成负库存；市价单仍只向零方向减仓，日终强制平仓。

`0913` 的求解器和回放实际上已经支持负库存。本轮不改动交易策略或现金流，只新增以下可核对内容：

- 每日最小/最大有符号库存；
- 正、负库存持有秒数及各自时间占比；
- 多头手秒与空头手秒；
- 每档 gamma 对负库存确实被访问、库存保持在对称边界内、日终归零的验证；
- 全部21档 gamma 与 `0913` 逐日成交、库存峰值及现金损益的一致性核对。

## 运行

在仓库根目录执行：

```bash
.venv/bin/python 0920/run_gamma_experiment.py --workers 3
.venv/bin/python -m unittest discover -s 0920/tests -v
.venv/bin/python 0920/build_gamma_report.py
```

主要输出：

- `output/report.html`：自包含技术报告；
- `output/gamma_summary.csv`：21档 gamma 汇总；
- `output/gamma_daily.csv`：逐日结果；
- `output/gamma_policy_surface.csv`：政策状态表；
- `output/gamma_results.json`：完整机器结果；
- `output/gamma_validation.json`：验证结果。

依赖本机行情缓存 `0824/data/july_2026/`。报告生成使用 Data Analytics 插件的标准自包含 HTML 打包器。

## 解释边界

允许负库存只表示回测库存和现金流可进入空头状态。当前实验没有建模借券可用性、借券费、强平规则、卖空限制或额外市场冲击，因此结果不能直接视为可执行做空收益。
